# Markdown Resumes

A version-controlled collection of my professional resumes written in Markdown.

This repository serves as the single source of truth for my resume development, allowing me to maintain multiple tailored versions for different roles while keeping a complete revision history through Git.

## Purpose

Instead of maintaining multiple independent Word or PDF files, I manage my resumes using Markdown. This approach provides:

- Version control with Git
- Easy customization for different job applications
- Reproducible PDF generation
- Clear history of changes
- Reusable resume sections

## Repository Structure

```
markdownResumes/
│
├── Base_template.md          # Master resume template
├── Base_template.txt         # Plain text version
│
├── images/                   # Logos, icons, and images
│
└── SentResumes/              # Customized resumes for applications
    ├── Company_A.md
    ├── Company_B.md
    └── ...
```

## Workflow

1. Update the master resume (`Base_template.md`).
2. Create a copy for a specific opportunity.
3. Tailor the experience, skills, and summary.
4. Export to PDF.
5. Store the customized version inside `SentResumes/`.
6. Commit every relevant change.

## Why Markdown?

Writing resumes in Markdown allows me to:

- Keep resumes lightweight and readable.
- Track every modification with Git.
- Easily convert documents to PDF or HTML.
- Reuse sections across multiple resume versions.
- Automate future resume generation workflows.
