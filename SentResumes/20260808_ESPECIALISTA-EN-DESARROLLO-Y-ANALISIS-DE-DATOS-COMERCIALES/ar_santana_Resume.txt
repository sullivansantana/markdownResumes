## NLP Author Attribution in Political Discourse

**Master's Thesis • INFOTEC • 2026**

### Project Summary

Engineered a large-scale NLP system processing **928K tweets** from 47 Mexican politicians, achieving **63.5% accuracy** and **60% macro F1-score** using contextual BERT embeddings.

### Key Achievements

* Processed **928,759 tweets** using a large-scale data processing and embedding pipeline.
* Generated **768-dimensional contextual representations** using BERT.
* Developed an MLP classifier with class weighting for imbalanced data.
* Applied **UMAP** for dimensionality reduction and exploratory analysis.
* Identified a relationship (`r² ≈ 0.45`) between tweet volume and classification performance.

### Tech Stack

`PyTorch` • `Transformers` • `TensorFlow/Keras` • `Scikit-learn` • `UMAP` • `NumPy/Pandas` • `CUDA`

### Impact

Developed a reproducible data science pipeline covering **data processing, transformation, analysis, modeling, evaluation, and visualization** for large-scale Spanish text data.
