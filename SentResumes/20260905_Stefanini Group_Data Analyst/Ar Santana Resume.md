# Featured Projects

## NLP Author Attribution in Political Discourse

Master's Thesis • INFOTEC • 2026

Developed an end-to-end NLP pipeline to process and classify 928,759 Spanish-language tweets across 47 author classes using Python and data science techniques.

* Processed and transformed 928K+ records using Python, Pandas, and NumPy.
* Evaluated multiple text embeddings and developed classification models using MLP and LinearSVC.
* Applied UMAP for dimensionality reduction and exploratory analysis of high-dimensional data.
* Achieved *71.84% accuracy and 0.70 Macro F1* using RoBERTuito + MLP, with class-level F1 ranging from *0.95 for LillyTellez to 0.40 for EdySmol*.
* Evaluated model performance using accuracy, precision, recall, Macro F1, and class-level metrics.
